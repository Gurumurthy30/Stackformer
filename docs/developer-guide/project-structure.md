# Project Structure

StackFormer adheres to modern Python packaging best practices by utilizing an explicit `src/` layout. This layout prevents accidental imports of uninstalled working-tree code, ensures tests run against the installed package, and enables clean editable installs.

## Source Directory Breakdown (`src/stackformer/`)

| Package / Module | Responsibility |
| :--- | :--- |
| `stackformer.modules` | The foundation of StackFormer: `BlockConfig`, `TransformerEncoder`, `TransformerDecoder`, `attention`, `feed_forward`, `normalization`, and `position_embedding`. |
| `stackformer.models` | Pre-assembled standard language model architectures (GPT-1, GPT-2, LLaMA-1, LLaMA-2, Gemma-1, BERT, RoBERTa, Vaswani Transformer). |
| `stackformer.vision` | Computer vision Transformer architectures: Vision Transformer (`ViT`) and `SegFormer`. |
| `stackformer.engine` | Execution engine: high-level `Trainer`, runtime step `Engine`, `TrainingState`, and SafeTensors `CheckpointManager`. |
| `stackformer.amp` | Automatic Mixed Precision abstraction layer wrapping `GradScaler` and `autocast`. |
| `stackformer.cache` | KV-cache implementations: `StaticKVCache` and `PagedKVCache`. |
| `stackformer.distributed` | Multi-GPU distributed training primitives: `wrap_model_ddp`, `distributed_sampler`, rank queries. |
| `stackformer.generate` | Autoregressive text generation loop and sampling strategies (greedy, temperature, top-k, nucleus top-p). |
| `stackformer.logging` | Unified logging multiplexer for CSV, TensorBoard, and Weights & Biases, plus `MetricTracker`. |
| `stackformer.optim` | Parameter grouping by weight decay eligibility, optimizer and scheduler factories, and custom loss functions. |
| `stackformer.utils` | Seed management, tensor operations, device queries, and attention helpers. |
